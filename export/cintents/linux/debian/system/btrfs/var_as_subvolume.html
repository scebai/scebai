- varをサブボリュームへ移行 -

/var を使用しているサービスを停止

$ sudo service rsyslog stop
$ sudo service exim4 stop
$ sudo service cron stop
$ sudo service clamav-freshclam stop

/var /usr/local /srv /opt をバックアップ

 mkdir baskup
 cd baskup/
 sudo cp -a /var ./var
 sudo cp /srv srv
 sudo cp -a /srv srv
 sudo cp -a /opt/ opt
 sudo cp -a /usr ./usr
 cd usr/
 sudo rm -r bin/ games/ include/ lib/ sbin/ share/ src/

/var /usr/local /srv /opt をunmount



/var で使用していたパーテイションを/mnt/var へマウント

$ sudo mkdir /mnt/var
$ sudo mount /dev/sda9 /mnt/var

サブボリューム作成

$ sudo btrfs subvolume create /mnt/var/@var
Create subvolume '/mnt/var/@var'
$ sudo btrfs subvolume create /mnt/var/@srv
Create subvolume '/mnt/var/@srv'
$ sudo btrfs subvolume create /mnt/var/@opt
Create subvolume '/mnt/var/@opt'
$ sudo btrfs subvolume create /mnt/var/@usr_local
Create subvolume '/mnt/var/@usr_local'

snapshots保存のsubvolumeを作成

$ sudo btrfs subvolume create /mnt/var/@snapshots
$ sudo mkdir /.snapshots

KVM Guestを保存するsubvolumeを作成

$ sudo btrfs suvolume create /mnt/var/@kvm_guests
$ sudo mkdir -P /var/lib/libvirt/images

mount後に下記のコマンドを実行し
ディレクトリの CoW を無効化する

$ sudo chattr +C /var/lib/libvirt/images

 

バックアップしたデータをコピー

$ sudo cp -a ~/work/baskup/usr/local/* @usr_local/
$ sudo cp -a ~/work/baskup/opt/* @opt/
$ sudo cp -a ~/work/baskup/srv/* @srv/
$ sudo cp -a ~/work/baskup/opt/* @opt/
