gentoo linuxをKVMGuestとしてinstall

install cd 起動 → VNCでsshサーバを設定し起動 → sshコンソールからインストール作業を行う

install script

gentoo2kvmGuest.sh

#! /bin/bash

sudo virsh destroy gentoo-template-01
sudo virsh undefine gentoo-template-01
sudo virsh list --all

sudo qemu-img create -f qcow2 /var/lib/libvirt/images/gentoo/gentoo-
tmplate01.qcow2 32g

sudo virt-install \
  --name gentoo-template-01 \
  --connect=qemu:///system \
  --disk path=/var/lib/libvirt/images/gentoo/gentoo-tmplate01.qcow2 \
  --network bridge=br0 \
  --graphics vnc,listen=0.0.0.0,password=zxcvbnm,keymap=ja,port=5911 \
  --hvm \
  -r 2048 \
  --vcpus=4 \
  --cdrom=/home/scebai/work/install-amd64-minimal-20180403T214502Z.iso \
  --os-type=linux \
  --os-variant=virtio26

$ sudo ./gentoo2kvmGuest.sh

VNC で操作

  • virt-install 起動後、VNC Viewwer でsshd server 起動までを操作
  • vnc viewwer
    vnc server --> KVM Host ip addresとportを指定
    gentoo2kvmGuest.sh内で指定したvncのポートに合わせる
